# Dr. Bruno Vasconcellos — Direito do Passageiro Aéreo

Pacote preparado para GitHub Pages.

URL pública prevista: https://drbrunovasconcellos.github.io/

## Publicação
1. Crie uma conta no GitHub, caso ainda não tenha.
2. Crie um repositório público com o nome exato `drbrunovasconcellos.github.io`.
3. Envie para a raiz do repositório todos os arquivos deste pacote.
4. Em Settings > Pages, confirme a publicação a partir do branch principal/root, se necessário.
5. Aguarde a disponibilização do endereço https://drbrunovasconcellos.github.io/

## Após publicar
- Abrir a Home em computador e celular.
- Testar os 7 fluxos da triagem.
- Testar Instagram, e-mail, WhatsApp e links internos.
- Confirmar a fotografia original `dr-bruno.jpg`.
- Conferir visualmente a imagem superior aprovada antes de divulgar o endereço.
- Cadastrar o site no Google Search Console e enviar `https://drbrunovasconcellos.github.io/sitemap.xml`.

## Observação importante
O pacote mantém a fotografia original presente na v50/v51. A imagem superior do avião aprovada anteriormente não foi recriada porque o ativo original não estava disponível no pacote de origem.
